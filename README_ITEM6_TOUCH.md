`C:\Users\lenovo\workspace_ccstheia\PWM`

没有使用之前误发的 `2026h-1`。原始 PWM 工程没有被覆盖，修改版项目名为
`PWM_ITEM6_TOUCH_TIME_TIMED`。

## 第六问执行流程

1. 用 S2 切换到第六问。
2. 确认摆杆水平零点已经设置；如果没有，手动调平后按 S3。
3. 队友按住视觉板 GPIO6 按键，在屏幕管道位置触摸目标点。
4. 视觉板发送 `T,目标厘米\r\n`，例如 `T,5.00\r\n`。
5. 小球自动移动到目标点。OLED 第一行显示：
   - `Z1`：摆杆零点有效。
   - `V1`：球位置视觉数据正常。
   - `P1`：已经收到触屏目标。
   - `R1`：球已在目标附近稳定，可以启动小车。
6. 只有显示 `R1` 后按 S1，小车才启动。
7. 小车运行期间锁定本次目标；运行中收到的新目标不会突然改变当前目标。
8. 返回终点后执行与第五问相同的软停，停车后继续保持所选位置。

S1 之前的动作是把球移动到现场选择的位置，不是车辆预倾斜。按下 S1 后，
小车PWM软起和摆杆运动前馈同时开始。

## 第六问与第五问共用的参数

第六问直接进入第五问现有函数和参数，没有复制另一套近似值：

- 直线 PWM：左 34、右 37。
- 圆弧 PWM：左 28、右 31。
- 软起：600 ms，从 0% 连续增加到当前基础 PWM。
- 起步固定前馈：-2.70°，持续完整的 600 ms S 曲线软起过程。
- 起步偏离目标时的减弱前馈：-0.60°。
- 巡航前馈：-0.05°。
- 编码器加速度前馈增益：2.20。
- 圆弧判断：巡线误差、转向量和左右编码器差共同判断。
- 圆弧进入确认：100 ms；直线恢复确认：250 ms。
- 软停：600 ms，从检测终点时的真实左右 PWM 按 S 曲线下降到 0。

车辆直线、圆弧 PWM 和软起/软停总时长没有修改；v6 仅把起步和第四问原来的线性 PWM 变化改成两端斜率为零的 S 曲线。

## 触屏目标参数

位于 `ball_vision_control/ball_config.h`：

- 目标范围：-10.0～+10.0 cm。
- 就绪位置误差：不超过 0.50 cm。
- 就绪球速：不超过 0.50 cm/s。
- 连续稳定时间：500 ms。

视觉程序位于 `vision/main.py`。它保留原来的球位置协议：

- `B,3.25,0.86\r\n`
- `B,X,0.00\r\n`

目标协议为：

- `T,5.00\r\n`

修改后的视觉程序会每 500 ms 重发一次已经选择的目标，防止一次报文丢失。

## 第四、五、六问停车捕球

v5 强制保持至少 3.20° 制动角，滤波速度反向滞后后会把球从最前端继续推到最后端。v6 已完全删除这段强制反打，改为让刹车前馈严格跟随车轮 PWM 的减速阶段：

- 第四问在最后 1.1 s 车轮降速开始时进入停车捕球。
- 第五、六问识别终点、进入 600 ms 真正软停时进入停车捕球。
- 起步 PWM 改为 S 曲线：摆杆与车轮仍同时启动，但最初约 200 ms 车辆加速度更缓，不进行停车等待式预倾斜。
- 起步前馈恢复到 -2.70°；第四至第六问瞬态摆杆斜坡仍为每 10 ms 变化 0.15°，第三问保持 0.12°。
- 中心区域不再关闭位置和速度反馈，使用连续的小位置反馈和较强速度阻尼稳定在目标附近。
- 新增仅供第四、五、六问使用的快速球速估计；第三问仍使用原来的速度滤波和参数。
- 第四问最后 1.1 s 也改成 S 曲线停车；第五、六问继续使用原来的 600 ms S 曲线停车。
- 刹车前馈在 PWM 开始下降时为 0，在减速中段达到峰值，在 PWM 归零时严格回到 0：第四问峰值 +1.20°，第五、六问峰值 +2.20°。
- PWM 归零后不再保留车辆减速度前馈，只剩小球位置/速度闭环。
- 停车速度增益降为 0.75，停车闭环角度上限降为 2.60°，避免前后全幅反打。
- 新增未平滑帧间速度的反向检测；真实小球一旦开始反向，立即按新方向制动，不等待滤波速度翻转。
- 车轮 PWM 到零后继续捕球，位置误差不超过 0.35 cm、球速不超过 0.25 cm/s，并连续稳定 400 ms 后退出。
- 捕球最多持续 3 s；即使未达到稳定条件，也会平滑交回原来的保持控制，不会卡住任务。
- 第四、五问保持目标仍为 0 cm；第六问保持触屏选择的位置。
- 摆杆目标仍经过原来的角度斜坡限制，不会从当前角度突然跳变。

v6 主要参数位于 `ball_vision_control/ball_config.h`：

```c
#define HOLD_STOP_POSITION_KP            0.18f

#define HOLD_STOP_MAX_ANGLE_DEG          2.60f
```

第四、五问 OLED 第二行暂时显示 `X` 和快速球速 `V`，数值均放大 10 倍。例如 `V:12` 代表 +1.2 cm/s。第六问第二行继续显示触屏目标位置。

## OLED 计时逻辑（第二至第六问）

- 每次按 S1 且当前题目真正启动成功时，从 `00.00 s` 开始计时。
- 使用 10 ms 系统计时节拍；OLED 每 100 ms 刷新一次，停止后保留到 0.01 s 的最终值。
- 正常完成、巡线故障或小球控制故障时立即冻结时间，便于记录成绩。
- 按 S2 切换题目或按 S3 重新标零时，时间清零。
- 第六问在小球未达到 `R1` 时按 S1 不会启动，因此也不会误计时。
- 第三问使用独立任务计时器，不依赖小车是否运行。

OLED 第一行示例：

- 第二问：第二行显示 `T:07.23`。
- 第三至第五问：`M4T07.23 B1Z1V1`。
- 第六问：`6T07.23 Z1V1P1R1`。
